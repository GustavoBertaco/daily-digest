## AWS What's New

**[[Preview Announcement] Re-introducing Forward Proxy as AWS Network Firewall Functionality](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-network-firewall-forward-proxy-preview/)**
AWS is consolidating its Network Firewall forward proxy into the main Network Firewall product. Originally launched in November 2025 as a standalone product with its own separate proxy security policy, the forward proxy capability is now integrated so customers can use their existing Network Firewall directly as an explicit forward proxy, retaining all existing filtering features.

**[Amazon Connect Customer now lets you export cases to CSV from the agent workspace](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-export-cases/)**
Amazon Connect agents can now export case data to CSV directly from the agent workspace. Agents choose which case fields to include; admins control export access via security profile permissions. Available across US East, US West, Canada, and European regions.

**[Amazon Bedrock launches Web Search for OpenAI GPT models](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-web/)**
Amazon Bedrock's built-in web search tool is now generally available for OpenAI's GPT-5.4, GPT-5.5, and GPT-5.6 (Sol/Terra/Luna) models. Search runs server-side entirely within AWS with zero data egress, eliminating the need for third-party search providers or separate API key management.

**[Run interactive workloads on Amazon EMR on EC2 with Spark Connect](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-emr-ec2-spark-connect/)**
EMR on EC2 now supports interactive Apache Spark sessions via Spark Connect. Data engineers can develop and debug from SageMaker Unified Studio managed notebooks or local IDEs (Jupyter, VS Code), with each session running on dedicated EMR clusters. Active and completed sessions are visible in the EMR console.

**[AWS Security Hub Extended adds supply chain security as its 10th category](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-security-hub-extended-adds-supply-chain-security)**
AWS Security Hub Extended adds Supply Chain Security as its 10th category, with Chainguard and Socket as curated partners. Teams can detect and block malicious open-source dependencies before they are built into applications, using the same pay-as-you-go pricing as other Security Hub Extended categories.

**[Amazon EC2 C8g instances now available in additional regions](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-c8g-instances-additional-regions/)**
Graviton4-based C8g compute-optimized instances expand to Europe (Paris), Africa (Cape Town), Israel (Tel Aviv), and Canada West (Calgary). These instances deliver up to 30% better performance than Graviton3-based instances for compute-intensive workloads such as HPC, batch processing, and video encoding.

**[AWS Application and Network Load Balancers now support RFC 9151 compliant security policies](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-application-network/)**
ALB and NLB add TLS security policies compliant with RFC 9151 and the NSA's Commercial National Security Algorithm (CNSA) 1.0 suite, covering both TLS 1.2 and TLS 1.3. Targeted at customers with mandated CNSA 1.0 requirements for secure communications.

**[Amazon S3 Vectors is now available in the AWS European Sovereign Cloud (Germany) Region](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-s3-vectors-european-sovereign-cloud-germany/)**
S3 Vectors, purpose-built vector storage for AI agents, RAG, and semantic search at billion-vector scale, is now available in the AWS European Sovereign Cloud (Germany) Region. It provides S3-level elasticity and durability without requiring provisioned infrastructure.

**[Amazon Connect Customer now supports capacity planning in 15 or 30 minute intervals](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-customer-interval-capacity-plan)**
Amazon Connect capacity planning now supports 15-minute and 30-minute granularity across Voice, Chat, Task, and Email channels. Interval-level plans capture intraday demand shifts — such as lunchtime chat surges or end-of-day call volume changes — enabling more precise staffing alignment.

**[Amazon EC2 I8g instances now available in AWS Europe (Paris), Asia Pacific (Jakarta) regions](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i8g-instances-aws-paris-jakarta-regions/)**
Storage-optimized I8g instances (Graviton4 processors + third-gen Nitro SSDs) are now available in Europe (Paris) and Asia Pacific (Jakarta). They offer up to 65% better real-time storage performance per TB, up to 50% lower storage I/O latency, and up to 60% lower overall storage latency compared to previous-generation storage-optimized instances.
