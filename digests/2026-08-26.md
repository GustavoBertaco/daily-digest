## Meta Engineering

**[MetaRoCE: A New RDMA Transport Built for AI-Scale Ethernet](https://engineering.fb.com/2026/08/24/networking-traffic/metaroce-rdma-transport-ai-ethernet/)**
Meta released MetaRoCE, a clean-sheet RDMA transport protocol purpose-built for AI workloads on commodity Ethernet, designed to move data between GPUs without wasting compute cycles at frontier model scale. The specification, a reference software implementation, and a compliance test suite are being released through the Open Compute Project (OCP) to enable broad industry adoption and interoperability.

**[MTIA 300: Meta's First Training Chip with Built-in NICs and Communication-Offloading Engines](https://engineering.fb.com/2026/08/24/networking-traffic/mtia-300-meta-training-chip-built-in-nics/)**
MTIA 300 is Meta's first in-house training and inference accelerator optimized for ranking and recommendation models, with built-in NIC chiplets that handle the communication demands of recommendation model training with superior performance over general-purpose GPUs. Meta co-designed the chip's communication library, HCCL, alongside the silicon itself — treating network communication as a first-class architectural concern from the ground up.

## AWS What's New

**[AWS Lambda functions now support full IAM resource-based policies](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-full-iam-resource-based-policies/)**
Lambda now supports the full capabilities of IAM resource-based policies, allowing admins to define granular permissions for multiple principals and actions in a single policy document using the complete range of IAM condition keys. Previously, Lambda functions required customers to add permissions individually per principal.

**[Amazon ECS now automatically detects and repairs container instances with impaired agent connectivity](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ecs-agent-connectivity-health)**
ECS now continuously monitors agent connectivity and automatically repairs container instances when infrastructure events — EBS volume degradation, host thermal events, or network failures — sever the agent's connection to the control plane. This reduces undetected workload failures without requiring manual intervention.

**[SageMaker MLflow now supports customer managed keys](https://aws.amazon.com/about-aws/whats-new/2026/08/sagemaker-mlflow-custom-keys)**
SageMaker MLflow can now encrypt data using customer-managed keys (CMK) via AWS KMS, with full audit capability through CloudTrail integration. This targets organizations with strict compliance requirements that cannot rely on AWS-managed keys for ML experiment data.

**[Amazon EKS now supports multiple external OIDC identity providers per cluster](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-eks-multiple-oidc-providers)**
EKS now supports up to 10 external OIDC identity providers per cluster, letting organizations associate distinct providers for different user populations — employees, contractors, CI/CD systems — without workarounds.

**[Amazon Aurora now supports PostgreSQL 18.4, 17.10, 16.14, 15.18, and 14.23](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-aurora-postgresql-18-4-17-10-16-14-15-18-14-23/)**
Aurora PostgreSQL-Compatible Edition now supports five new minor versions including 18.4, incorporating community bug fixes, CVE patches, and Aurora-specific enhancements. AWS recommends upgrading via scheduled maintenance windows using automatic minor version upgrades.

**[Amazon SageMaker HyperPod enhances support for Ray](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-sagemaker-hyperpod-ray)**
HyperPod now provides built-in observability, resilient training, accelerated inference, and managed development environments for Ray workloads on Kubernetes — directly addressing production pain points including job hangs, low GPU utilization from static team allocations, and multi-step operational overhead.

**[Amazon Connect Customer now supports information extraction for agent voice and chat conversations](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-customer-information/)**
Amazon Connect now automatically captures both verbatim values (account numbers, reservation IDs, product names) and derived insights inferred from conversation (reason for contact, resolution provided, next steps promised) from voice and chat interactions. Extraction rules are configurable, reducing manual data entry and improving productivity for agents and supervisors.

**[AWS ParallelCluster 3.16 adds an on-node diagnostics tool](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-parallelcluster/)**
ParallelCluster 3.16 ships `pcluster-diag`, a diagnostics tool built into the AMI that runs structured checks on any cluster node with a single command and returns a structured report. The release also hardens the cluster lifecycle with more resilient creation, updates, and image builds, and refreshes the HPC and AI/ML software stack.

**[OpenAI GPT-5.6 Terra and Luna now available on Amazon Bedrock in AWS GovCloud (US)](https://aws.amazon.com/about-aws/whats-new/2026/08/openai-gpt-terra-luna-govcloud/)**
GPT-5.6 Terra and Luna are now generally available on Bedrock in both GovCloud regions (US-West and US-East), bringing OpenAI's latest model family to Bedrock's high-performance inference engine in the government cloud. Terra and Luna span two capability tiers — balanced performance and higher-capability — within the GPT-5.6 family.

**[Amazon RDS for MySQL now supports new minor version 8.4.11](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-rds-mysql-8411-available/)**
RDS for MySQL now supports MySQL 8.4.11, which introduces post-quantum TLS (PQ-TLS) key exchange for encrypting data in transit alongside the standard CVE fixes and bug patches from the community release. AWS recommends upgrading to benefit from both the security improvements and the new post-quantum cryptography option.
