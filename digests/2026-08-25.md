## Meta Engineering

**[MetaRoCE: A New RDMA Transport Built for AI-Scale Ethernet](https://engineering.fb.com/2026/08/24/networking-traffic/metaroce-rdma-transport-ai-ethernet/)**
Meta designed MetaRoCE, a clean-sheet RDMA transport protocol purpose-built for AI workloads on commodity Ethernet, to move data between GPUs without wasting compute cycles during training and serving frontier AI models. Meta is releasing the MetaRoCE specification, a reference software implementation, and a compliance test suite through the Open Compute Project (OCP) to enable broader industry adoption.

**[MTIA 300: Meta's First Training Chip with Built-in NICs and Communication-Offloading Engines](https://engineering.fb.com/2026/08/24/networking-traffic/mtia-300-meta-training-chip-built-in-nics/)**
MTIA 300 is Meta's first in-house training and inference accelerator optimized for ranking and recommendation models, with built-in NIC chiplets that deliver superior communication performance over general-purpose GPUs. Meta co-designed the chip alongside its communication library, HCCL, treating communication as a first-class design concern.

## AWS What's New

**[AWS Lambda functions now support full IAM resource-based policies](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-full-iam-resource-based-policies/)**
AWS Lambda now supports full IAM resource-based policies, letting platform admins and security teams define granular permissions for multiple principals and actions in a single policy document using the full range of IAM condition keys. Previously, Lambda required adding permissions individually per principal.

**[Amazon ECS now automatically detects and repairs container instances with impaired agent connectivity](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ecs-agent-connectivity-health)**
Amazon ECS now automatically detects and repairs container instances with impaired agent connectivity, reducing undetected workload failures and improving application availability without manual intervention. ECS continuously monitors agent connectivity and can respond to infrastructure events such as EBS volume degradation, host thermal events, or network failures that sever the ECS agent's control-plane connection.

**[SageMaker MLflow now supports customer managed keys](https://aws.amazon.com/about-aws/whats-new/2026/08/sagemaker-mlflow-custom-keys)**
SageMaker MLflow now supports customer-managed keys (CMK) through AWS KMS, giving organizations with strict security and compliance requirements full control over their own encryption keys. AWS CloudTrail integration provides comprehensive audit capabilities for tracing data access.

**[Amazon EKS now supports multiple external OIDC identity providers per cluster](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-eks-multiple-oidc-providers)**
Amazon EKS now supports up to 10 external OIDC identity providers per cluster, removing the previous one-provider limit. Organizations can associate separate providers for different user populations — such as employees, contractors, and CI/CD systems — directly with a single cluster.

**[Amazon Aurora now supports PostgreSQL 18.4, 17.10, 16.14, 15.18, and 14.23](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-aurora-postgresql-18-4-17-10-16-14-15-18-14-23/)**
Amazon Aurora PostgreSQL-Compatible Edition now supports PostgreSQL versions 18.4, 17.10, 16.14, 15.18, and 14.23, incorporating community bug fixes and Aurora-specific enhancements. AWS recommends upgrading to the latest minor versions to address known CVEs.

**[Amazon SageMaker HyperPod enhances support for Ray](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-sagemaker-hyperpod-ray)**
Amazon SageMaker HyperPod now adds built-in observability, resilient training, accelerated inference, and managed development environments for Ray workloads. Ray is a popular open-source framework for scaling AI workloads across data processing, distributed training, reinforcement learning, and model serving.

**[Amazon Connect Customer now supports information extraction for agent voice and chat conversations](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-customer-information/)**
Amazon Connect Customer now supports information extraction, automatically capturing verbatim values such as account numbers and reservation IDs, as well as derived insights including reason for contact and next steps promised. This reduces manual data capture and improves agent and supervisor productivity.

**[AWS ParallelCluster 3.16 adds an on-node diagnostics tool](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-parallelcluster/)**
AWS ParallelCluster 3.16 is now generally available with pcluster-diag, a diagnostics tool built into ParallelCluster AMIs that runs checks on any cluster node with a single command and produces a structured report. This release also hardens cluster lifecycle operations with more resilient cluster creation, updates, and image builds.

**[OpenAI GPT-5.6 Terra and Luna now available on Amazon Bedrock in AWS GovCloud (US)](https://aws.amazon.com/about-aws/whats-new/2026/08/openai-gpt-terra-luna-govcloud/)**
GPT-5.6 Terra and Luna are now generally available on Amazon Bedrock in AWS GovCloud (US-West) and AWS GovCloud (US-East), bringing OpenAI's latest model family to Bedrock's next-generation inference engine built for high performance, security, and reliability. The two models span capability tiers from balanced performance (Terra) to higher intelligence per token.

**[Amazon RDS for MySQL now supports new minor version 8.4.11](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-rds-mysql-8411-available/)**
Amazon RDS for MySQL now supports MySQL 8.4.11, which introduces post-quantum TLS key exchange for encrypting data in transit alongside operational improvements. AWS recommends upgrading to accept CVE fixes from prior versions.
