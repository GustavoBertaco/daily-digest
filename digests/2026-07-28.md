# 🤖 AI & Machine Learning

## AI Engineer

**[DeepSWE: A Contamination-Resistant Coding Benchmark — James Shi, Datacurve](https://www.youtube.com/watch?v=Yk87oUPVaxU)**
James Shi presents DeepSWE, a 113-task software engineering benchmark designed to eliminate the training-data contamination that distorts leaderboard scores — every task is authored from scratch by engineers who actually maintain the target open-source repository, not harvested from public pull requests.

- **Contamination is the unaddressed variable on current leaderboards.** Tasks scraped from real PRs can surface in pretraining data; hand-authored tasks for the same codebase close that gap without changing the domain.
- **Long-horizon scope, not micro-completions.** Each problem requires end-to-end reasoning within a real repository rather than filling in a single function — closer to actual engineering work.
- **Behavioral verification over self-report.** Isolated environments and program-based verifiers check observable output, not the model's own account of whether it succeeded.
- **Clean evaluation changes the leaderboard shape.** Once contamination is removed, scores stop clustering — suggesting current tight groupings reflect shared contamination more than genuine capability separation.
