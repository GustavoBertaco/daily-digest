# 🤖 AI & Machine Learning

## AI Engineer

**[What Runs Where? Local AI in Production — Ahmad Osman, Osmantic](https://www.youtube.com/watch?v=GKSQYbELDzw)**
Ahmad Osman's thesis: deploying a capable local model is fundamentally a hardware and runtime selection problem. The model is table stakes — quantization, memory bandwidth, batching, and inference engine choice determine whether production workloads actually land.

- **Hardware and inference engine come before model selection.** Osman walks through quantization, memory bandwidth, and batching as the primary performance levers for local inference, arguing that getting the stack right matters more than the model choice alone.
- **Specialized models outperform generalists on real workloads.** Osman makes the case for purpose-built, specialized models over general-purpose alternatives when targeting real production workloads.
- **Local inference is a component in the agent stack, not a standalone choice.** Osman connects on-device performance to agent harnesses and evaluation traces, treating local deployment as part of a wider orchestration system.
- **GPU ownership shifts the cost-control calculus.** He addresses the economics of owning hardware versus API-based inference, arguing the case for local GPU ownership in certain deployment scenarios.
- **Continual learning on machines you control is a strategic lever.** Running models on hardware you own creates the option to update and refine continuously — Osman presents this as a durable reason for local deployment.
