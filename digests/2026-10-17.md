## The Knowledge Project Podcast

**[Avoid This Social Mistake](https://www.youtube.com/watch?v=L1k-WeKrtIk)**
Ryan Serhant, founder of SERHANT., argues that most people sequence relationship-building backwards — they ask before they have established trust. The fix is a two-step opener with anyone you just met: an authentic compliment, then finding common ground, before any request.

- **Trust is a prerequisite, not a byproduct.** Serhant is explicit: "trust comes first and the ask comes after." Skipping that sequence is the social mistake the title names.
- **The compliment must be authentic.** The word "authentic" is load-bearing — a transactional opener signals the ask is already in motion and defeats the rapport it was meant to build.
- **Common ground is the bridge.** Identifying something shared creates a relational foundation that makes a subsequent request feel natural rather than extractive.
- **It is immediately actionable.** Serhant frames this as a technique you can apply in your very next conversation — no warm-up period required.

## AWS What's New

**[Web Search on Amazon Bedrock AgentCore expands to AWS GovCloud and 3 Regions](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore/)**
Web Search on Amazon Bedrock AgentCore — a fully managed tool that grounds AI agents in current web content for research, summarization, and Q&A — is now available in US East (Ohio), US West (Oregon), Asia Pacific (Sydney), and AWS GovCloud (US-West). The expansion lets customers deploy web-grounded agents closer to their applications and end users across these four regions.

**[Amazon SageMaker Studio simplifies getting started for new AI/ML builders with new sign-in options](https://aws.amazon.com/about-aws/whats-new/2026/10/sagemaker-studio-new-sign-in-options/)**
SageMaker Studio now lets new customers sign in with Google, GitHub, or Apple credentials and land directly in a fully configured environment — eliminating the previous multi-step requirement to create an AWS account, provide a credit card, navigate the console, and configure IAM permissions before accessing a model.

**[Amazon EC2 T8i instances are now available in South America (São Paulo)](https://aws.amazon.com/about-aws/whats-new/2026/10/ec2-t8i-instances-south-america/)**
EC2 T8i instances, powered by custom sixth-generation Intel Xeon 6 processors on sixth-gen AWS Nitro cards, are now available in São Paulo. They offer up to 30% better price-performance than T3 instances in nano, micro, small, and medium sizes for low-to-moderate CPU workloads.

**[Amazon DynamoDB Streams now supports timestamp-based stream processing](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-dynamodb-streams-timestamp-processing)**
DynamoDB Streams adds the AT_TIMESTAMP shard iterator type, letting consumers begin reading from a specific point in time rather than being limited to the oldest retained record (up to 24 hours) or records written after consumption starts. This enables more precise event replay and stream-recovery workflows.

**[AWS Lambda Durable Execution SDK for Go is now generally available](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-lambda-durable-go-sdk-support/)**
Go developers can now build resilient long-running Lambda workflows — including infrastructure automation, deployment rollouts with approval gates, and AI pipelines with human review steps — without implementing custom progress tracking. Multi-step orchestration is expressed directly in Go code via durable functions.

**[Muse Spark Open model now available on Amazon SageMaker JumpStart](https://aws.amazon.com/about-aws/whats-new/2026/01/muse-spark-open-on-sagemaker-jumpstart/)**
Meta's Muse Spark Open, a coding-optimized open-weight model built on a Mixture-of-Experts architecture for agentic coding workflows with multi-step reasoning and tool calling, is now deployable via SageMaker JumpStart. The model is purpose-built for long-running coding agents and multimodal engineering workflows on AWS infrastructure.

**[AWS HealthOmics now supports shared VPCs](https://aws.amazon.com/about-aws/whats-new/2026/10/omics-workflows-shared-vpcs/)**
AWS HealthOmics workflows can now access VPCs managed by other AWS accounts via AWS Resource Access Manager, enabling centralized networking administration across account boundaries. This applies to the HIPAA-eligible bioinformatics workflow service, supporting shared subnets and security group configurations.

**[Amazon Time Sync Service adds support for microsecond-accurate time on 135 additional EC2 instance types in all commercial regions](https://aws.amazon.com/about-aws/whats-new/2026/10/time-sync-additional-instances-all-regions)**
Microsecond-accurate time and nanosecond-precision hardware timestamps are now available across 135 additional EC2 instance types spanning 12 instance families in all commercial regions. The capability leverages Nitro System reference clocks to help distributed applications order events and measure one-way network latency.

**[AWS Transform for full-stack Windows modernization now supports Aurora PostgreSQL cross-region deployment in 7 more Regions](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transform-full-stack-aurora-cross-region)**
AWS Transform adds cross-region deployment for converted Aurora PostgreSQL databases and expands to seven additional AWS regions, giving customers control over data residency, latency, and disaster recovery placement after SQL Server modernization. Customers upload SQL Server DDL files and designate a target region for the converted database.

**[Amazon MSK Connect and AWS Glue Schema Registry are now available in the AWS European Sovereign Cloud (Germany) region](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-msk-connect-aws-gsr-additional-aws-regions)**
