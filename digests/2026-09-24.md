# 🤖 AI & Machine Learning

## AI Engineer

**[Modality Misalignment and Originality Attribution in Short-Form Video — Aditya Gautam, Meta](https://www.youtube.com/watch?v=jNE8No-wvok)**
Aditya Gautam at Meta works on two interrelated problems in short-form video at scale: detecting mid-video modality mismatches (a clip that shifts topics within seconds) and identifying unoriginal AI-generated content that corrodes attribution. Both problems share the same constraint: adversarial, multilingual, drifting data with no ground truth.

- **Temporal mismatch is the unsolved variant.** Cross-modal mismatch (e.g., audio vs. video) is a largely solved embedding problem; the open problem is mismatch *within* a single modality over time — a video that is about sports for its first six seconds, then turns political for half a second.
- **Scale makes even low error rates unacceptable.** At over one hundred million videos, adversarial uploads are a deliberate noise source and the sheer volume means even small failure rates produce massive absolute counts.
- **AI tools have made unoriginal content a structural attribution problem.** Trivial AI-generated duplicates are corrosive to attribution systems because they flood the signal with near-identical content, making the original harder to identify.
- **No clean ground truth exists across these data types.** Models must handle multilingual on-screen text, distribution drift, and adversarial manipulation simultaneously — without labeled data to anchor training.

**[Skill issue: stop deploying vision language models, use them with Skills — Merve Noyan, Hugging Face](https://www.youtube.com/watch?v=dKcTBQzR7jI)**
Merve Noyan, author of a book on vision language models, argues that practitioners systematically over-apply VLMs where small, task-specific detectors would outperform them — and that licensing negligence around computer vision models is a real production risk that her new toolkit addresses.

- **VLMs cannot do real-time inference on video streams.** A small detector trained for a specific task runs at forty frames per second on commodity hardware and beats the VLM on that task. Defaulting to a VLM where a targeted model exists is a performance and cost mistake.
- **Copyleft licensing on popular detectors is an overlooked deployment trap.** Developers routinely deploy widely-used detectors without checking their licenses; a copyleft condition on a core vision component can constrain an entire product's distribution.
- **Her toolkit uses a coding agent as a "clueless compiler."** It hands Apache 2.0-licensed models to an agent that assembles task-specific pipelines — decoupling model selection from pipeline construction and keeping the license stack clean.
- **The core argument is fit-for-purpose tool selection.** VLMs belong in open-ended visual understanding; specialized detectors belong wherever there is a defined, repeatable visual task with latency requirements.

**[Building the Document Context Layer for AI Agents — Jerry Liu, LlamaIndex](https://www.youtube.com/watch?v=RQi7x-navxU)**
Jerry Liu of LlamaIndex argues that document understanding is still an unsolved problem because PDFs encode layout, not semantics — and that RAG in 2026 has structurally separated into an agent harness (handling retrieval reasoning) and a dedicated document context layer (handling parsing and representation).

- **PDFs are a layout format, not a document format.** Text is stored as glyphs with coordinates; tables are line segments with characters at cell positions; reading order for multicolumn pages is not stored anywhere. Feeding a raw file to an agent is handing it a printer instruction set.
- **Document OCR has remained unsolved for twenty years.** The structural mismatch between how PDFs encode information and what agents need to reason about is a persistent hard problem — not merely an engineering task awaiting more compute.
- **RAG has split into two distinct layers.** Retrieval complexity has moved into the agent harness, which now reasons about what to retrieve and when; the context layer is responsible for turning raw documents into something an agent can actually use.
- **Underinvesting in the context layer caps agent reasoning quality.** Even a sophisticated retrieval strategy cannot compensate for broken document representation — wrong reading order or lost table structure creates a ceiling that model capability alone cannot raise.
