## AI Engineer

**[The Dark Arts of Skill Engineering — Paul Bakaus, Renaissance Geek (Impeccable)](https://www.youtube.com/watch?v=SQMCtZX3trg)**
Bakaus argues that the visual monoculture of AI-generated design is structurally the same problem as CSS framework and jQuery UI defaults: most people ship the default, so the default becomes the dominant aesthetic. Having written jQuery UI and shipped its orange default theme to the web, he speaks from the position of someone who created this dynamic — not a critic observing it from outside.

- **Defaults persist because customization requires active effort.** Bakaus shipped jQuery UI with an orange default theme assuming people would change it; they didn't, and the web turned orange. The same inertia now shapes AI-generated design.
- **AI design has its own recognizable default palette.** Just as uncustomized CSS frameworks produced the purple gradients that became a signal of laziness, AI-generated work now produces what the snippet describes as its own "house shade of beige."
- **Banning the tool relocates the problem, it doesn't solve it.** Bakaus' central claim is that prohibiting AI-generated aesthetics doesn't produce originality — it just shifts where the default aesthetic comes from.
