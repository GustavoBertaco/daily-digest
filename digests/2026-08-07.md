## AWS What's New

**[AWS Lambda announces scalable network bandwidth up to 3,000 Mbps for functions outside a VPC](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-network-bandwidth/)**
Lambda functions outside a VPC with 2 GB or more of memory now get proportionally scaling network bandwidth — from 625 Mbps at 2 GB up to 3,000 Mbps at 10 GB — targeting latency-sensitive data processing workloads that need to transfer large data volumes. No configuration changes are required beyond meeting the memory threshold.

**[Amazon Keyspaces (for Apache Cassandra) is now available in the Canada West (Calgary) Region (ca-west-1)](https://aws.amazon.com/about-aws/whats-new/2025/11/amazon-keyspaces-apache-cassandra-canada-west/)**
Amazon Keyspaces is now available in ca-west-1, letting customers in the Canada West region build Cassandra-compatible applications with lower latency while keeping data in-region to meet data residency requirements. Keyspaces is serverless and billed only for resources consumed.

**[AWS Glue Data Quality makes ETL anomaly detection free and improves anomaly predictions](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-glue-data-quality-anomaly-detection-free)**
Glue Data Quality removes pricing for anomaly detection in ETL jobs and introduces an observation mode that switches from a linear trend to a constant baseline, reducing false positives for workloads with irregular data arrival intervals. Notebook-based and exploratory workflows now benefit from more accurate alerts with less noise.

**[AWS Marketplace adds AI Insights so buyers can understand pricing before they buy](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-marketplace-ai-insights/)**
AI Insights, now in the pricing section of every AWS Marketplace listing, explains each product's pricing in plain language — what a unit maps to, how bills change as usage scales, how multiple pricing dimensions combine, and what is and isn't included — without requiring buyers to piece together information from multiple external sites.

**[Amazon DynamoDB now supports real-time vector search](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-dynamodb-vector-search)**
DynamoDB now offers generally available native vector search with single-digit millisecond latency at 99%+ recall, designed to scale to trillions of vectors without the traditional trade-off between search speed, scale, and accuracy. No servers to provision, patch, or manage.

**[AWS IAM Identity Center makes management of AWS account access optional for new organization instances](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-identity-center-accounts-optional/)**
New IAM Identity Center organization instances can now be configured to manage AWS application access only, skipping AWS account access management entirely. The option is available only at initial configuration and does not affect existing instances.

**[Amazon Aurora serverless now scales faster to support agentic AI and other bursty workloads](https://aws.amazon.com/about-aws/whats-new/2026/08/aurora-serverless-instant-12-acu-scaling)**
Aurora Serverless now reaches up to 12 ACUs within a second at the start of a scale-up event, continuing to scale to 256 ACUs as load grows, then scaling back to zero when idle. The faster burst profile is explicitly designed for agentic AI workloads, which have unpredictable traffic spikes and long idle windows.

# 🤖 AI & Machine Learning

## AI Engineer

**[Gadgets: Personal app vibe coding that is actually safe — Kenton Varda, Cloudflare](https://www.youtube.com/watch?v=RmS5s6Wbin4)**
Kenton Varda's thesis: AI-assisted personal app building ("vibe coding") can be safe not by restricting what the AI does, but by having it extend the application itself — Claude adds missing capabilities directly into the app on demand, staying within the application boundary rather than operating on the broader system.

- **The demo is the entire argument.** When a presentation app lacked strikethrough, Claude added the feature to the app. When building a deck from a Google doc required SVG diagrams the app couldn't render, Claude added an SVG input box and generated the diagrams within it. Each move is an extension of the app, not an escape from it.
- **Safety through scope, not restriction.** The model's output is bounded by the application. When the AI can only modify the app rather than act on the surrounding system, the risk profile changes fundamentally — the app itself becomes the sandboxed execution environment.
- **Previews Cloudflare OS.** The snippet notes this talk was recorded a month before Cloudflare OS launched; the patterns Varda demonstrates here likely reflect design principles carried into that release.
