## Daniel Pink

**[30 Cheat Codes to Beat Every Level of Life](https://www.youtube.com/watch?v=c7jGXPEY54k)**
Daniel Pink argues that life, like a video game, has cheat codes — the difference is that nobody hands you the list. He shares 30 heuristics collected over years, spanning decisions, people, productivity, work, and life itself, framed explicitly as what he wishes someone had told him at 25.

- **Life has patterns, not secrets.** The "cheat codes" framing repositions practical wisdom as learnable, reusable patterns available to anyone — not privileged insight reserved for the experienced.
- **Five domains, deliberately broad.** The 30 codes span decisions, people, productivity, work, and life — a wide lens rather than single-topic depth, acknowledging that most hard situations don't fit a single category.
- **The 25-year-old frame is intentional.** Marking these as what Pink wished he knew at 25 signals the list is aimed at closing the gap between inexperience and hard-won pattern recognition, not refining the already seasoned.
- **Designed as a reference artifact.** The companion one-page list at danpink.com/life-cheat-codes is explicitly built to be consulted without rewatching — practical rather than merely inspirational.

**[The Score by C Thi Nguyen](https://www.youtube.com/watch?v=7x05A5MUKE0)**
Philosopher C. Thi Nguyen examines how scores and metrics seduce through clarity — we trust quantified things not because they are truer, but because they feel settled. He extends this pattern, which he calls "the seductions of clarity," beyond games: scores, he argues, are the purest expression of it.

- **Games hand you a temporary self.** Nguyen's core claim from *Games: Agency as Art*: games work by giving players crisp goals and clean scoring — that temporary, borrowed self is the artistry of the form, not incidental to it.
- **The medium of games is you.** Framing games as an art form whose medium is the player's agency distinguishes Nguyen's argument from standard game design or game theory literature — the player is the material being shaped.
- **Clarity is not truth.** The "seductions of clarity" thesis: ideas that feel lucid and settled get trusted regardless of accuracy. Scores are the purest version of this trap — quantified, so seemingly objective.
- **Scores as the endpoint of the seduction.** Nguyen positions scores as the purest expression of clarity's appeal — the form in which the seduction is most complete.

## AWS What's New

**[AWS Continuum now supports credential testing and accessible domain suggestions](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-security-agent/)**
AWS Continuum, a frontier agent for on-demand penetration testing, now lets developers test login credentials and receive suggested domain names before a test run begins. This reduces misconfiguration and wasted test cycles by making it easier to define an accurate network scope upfront.

**[Amazon ECS Express Mode now supports AWS Graviton (ARM64) workloads](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ecs-express-mode-arm-architecture/)**
Amazon ECS Express Mode now supports ARM64 as the CPU architecture for services, enabling deployment of ARM-based container images on AWS Graviton-powered compute. AWS claims up to 40% better price-performance compared to equivalent x86-based instances.

**[AWS Resilience Hub adds three new capabilities](https://aws.amazon.com/about-aws/whats-new/2026/09/resilience-hub-eks-dependency-policy/)**
AWS Resilience Hub — which provides automated dependency discovery, generative AI-powered failure mode analysis, modular resilience policies, and org-wide resilience posture reporting — adds EKS labels support for service input sources, along with two additional new capabilities not fully captured in the snippet.

**[AWS RTB Fabric now supports configurable Availability Zone affinity](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-rtb-fabric-configurable-availability-zone-affinity/)**
AWS RTB Fabric now lets AdTech companies configure whether partner connections reach a responder gateway within the partner's own Availability Zone or across any AZ the gateway spans. The feature is available at no extra charge and targets DSPs and SSPs running latency-sensitive bidding infrastructure.

**[Kimi K3 by Moonshot AI is now generally available on Amazon Bedrock](https://aws.amazon.com/about-aws/whats-new/2026/09/moonshot-ai-kimi-k3-on-amazon-bedrock/)**
Kimi K3, Moonshot AI's most capable model and, according to Moonshot AI, the first open model to reach 2.8 trillion parameters, is now generally available on Amazon Bedrock. It combines native vision capabilities with a 1-million-token context window, targeting long-running coding and knowledge work tasks.

**[Amazon SNS now supports message payloads up to 1 MiB](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-sns-1mib-support)**
Amazon SNS now supports message payloads up to 1 MiB — a 4x increase from the previous 256 KiB limit — allowing larger messages to be published to SNS topics. The increase targets application integration, IoT, and generative AI workloads that increasingly exchange larger volumes of data per message.

**[The new AgentCore Runtime is now available in Amazon Bedrock AgentCore](https://aws.amazon.com/about-aws/whats-new/2026/09/new-agentcore-runtime-generally-available)**
The next-generation AgentCore Runtime brings elastic memory management that reclaims unused memory throughout a session — so you pay for actual usage rather than peak — plus consistent cold start times regardless of container image size or concurrency. The serverless microVM model retains its existing model: no pre-provisioning, scale to zero, and hardware-enforced session isolation.

## AI Engineer

**[Total Recall: Agent Memory and Harness Engineering — Ignacio Martinez, Oracle](https://www.youtube.com/watch?v=xs-ob87TTzg)**
Ignacio Martinez from Oracle makes the case that harness engineering — not model selection — is the primary lever over agent behavior. His central argument: the LLM is the frozen, rented part of the system; the weights do not change. Everything that differentiates an agent lives in the harness built around it.

- **The model is the frozen layer.** Martinez's core claim is that LLM weights are static and rented; all meaningful engineering decisions — memory, context management, tool wiring — happen in the harness, not the model itself.
- **Harness engineering is a first-class discipline.** The workshop is framed as one of the more carefully constructed arguments for treating harness design as a serious engineering practice rather than scaffolding bolted on after model selection.
- **Memory is the hard design problem.** The "Total Recall" framing and workshop focus signals that agent memory — what to retain, when to retrieve it, and how to structure it — is where the real harness difficulty lives.
- **Practitioner-built, not polished marketing.** Martinez registered the workshop domain the Saturday before giving it and paid for attendees' GitHub Codespaces himself — context that marks this as hands-on practitioner content, not a vendor keynote.
