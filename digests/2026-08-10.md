# 🤖 AI & Machine Learning

## AI Engineer

**[Realtime multiplayer, automation, and you! — Idan Gazit, GitHub](https://www.youtube.com/watch?v=iQ5xldZ9StU)**
Idan Gazit shows how a short plain-English agentic workflow — drafted as the kind of message you would send a teammate — can handle multi-major-version framework upgrades end-to-end, from changelog parsing to opening a pull request.

- **Plain English is the interface.** The workflow started as roughly three lines of natural language; Copilot expanded those into a full structured playbook covering new-release checks, changelog reading, code changes, and PR creation.
- **Two major versions in one run.** The agent carried the site from Astro 5 to Astro 7, finding and fixing breakages in between, without manual intervention at each step.
- **A fast-shipping dependency makes the case.** Astro's release cadence keeps Gazit permanently on the upgrade treadmill; that frequent pain is what makes automation worthwhile where a stable framework would not.

**[Benchmarking Coding Agents on New vs Legacy Codebases — Denys Linkov, Wisedocs](https://www.youtube.com/watch?v=7vn4WpqNpck)**
Denys Linkov ran an honest audit of coding agents against Wisedocs' real medical-document pipeline — ML models spread across ten repositories nobody enjoyed touching — and asked whether six months of manual monorepo consolidation should have been spent waiting for the models to mature enough to do it themselves.

- **The benchmark is one concrete refactor task.** A single, repeatable refactor operation applied across both the old multi-repo layout and the new monorepo serves as the yardstick for comparing agent capability.
- **o3 took three hours of back-and-forth.** Even with a top model, the task required prolonged iteration, pointing to the gap between current agent capability and production-ready automation.
- **Legacy codebases are a distinct problem class.** Medical claims PDFs over 10,000 pages in a ten-repo fragmented pipeline are not typical benchmarks; the talk surfaces how agent performance degrades on messy, real-world codebases versus clean greenfield code.
- **The "should we have waited?" question is real.** Having consolidated manually, the team is now positioned to answer whether AI-assisted migration would have been faster — and the answer is not obvious.

**[Anthropic's CCA Exam as a Field-Guide for Agentic Engineering — Frank Coyle, UC Berkeley](https://www.youtube.com/watch?v=Z-c11pV_uvU)**
Frank Coyle uses the Claude Certified Architect exam — six production scenarios, four drawn at random — as a practitioner's field guide to agentic engineering, structured around the anti-pattern in each scenario before showing what good looks like.

- **Anti-pattern first, then the fix.** Leading with failure modes is more instructive than presenting best practices directly; the same approach powered the 1990s design-patterns movement and its catalog of the moves that quietly ruin systems.
- **The CCA exam is a production readiness checklist in disguise.** Six scenarios picked at random require breadth across the full problem space — preparation by optimising for one narrow domain will not work.
- **Customer support anti-pattern: call, respond, use.** The naive agentic pattern is calling the model, taking its response, and acting on it directly. The correct architecture adds more structure around the response.
- **Agentic engineering has a repeatable catalog of failure modes.** Naming those failures explicitly, as the talk does, is the mechanism for accelerating the field the same way named design patterns did.

**[The New Primitives: Building AI Native Software — Kwindla Kramer, Daily](https://www.youtube.com/watch?v=LZuWZRze3MU)**
Kwindla Hultman Kramer argues that AI agents are to software development today what the web page was in 1995 — a new primitive that looks like a destination but will turn out to be scaffolding for something we cannot yet name.

- **Vannevar Bush's 1945 essay as a mirror.** "As We May Think" described document scanning, OCR, speech to text, hypertext, search engines, and voice interfaces before any of it existed — the same way today's agent primitives may be invisible predecessors of a richer AI-native future.
- **Web pages were a primitive, not a destination.** Kramer's uncomfortable autobiographical point: the excitement he felt writing HTML by hand in 1995 is the same excitement he feels about agents now, and web pages turned out to be scaffolding, not the final form.
- **Agents are the new primitive.** We are at the "hand-coded HTML" stage of agent development — foundational, but not the endpoint of what AI-native software will become.
- **The framing changes what you build.** Treating agents as a primitive rather than a destination reshapes how you layer abstractions and what "AI-native software" will ultimately mean.

**[Open Source Is Dead. Long Live Open Source. — Saoud Rizwan, Cline](https://www.youtube.com/watch?v=CoEIs6Xm8m8)**
Saoud Rizwan uses the litellm supply-chain compromise — a backdoor installed in a package pulling 3.5 million downloads a day, live for three hours and caught only by accident — to argue that the open-source trust model has fundamentally broken down in the AI era.

- **litellm was compromised at scale.** A malicious release installed a credential harvester targeting API keys, SSH keys, and crypto keys, plus a backdoor for remote command execution, inside a package with 3.5 million daily downloads.
- **Detection was accidental.** The malware had a bug that crashed Cursor; a researcher went looking. Without that crash, the attack could have persisted undetected.
- **The trust model has crossed a threshold.** The incident marks a new level of threat: well-regarded, widely-used open-source packages in the AI ecosystem are now targeted with attacks sophisticated enough to evade routine detection.
- **Zig banned AI from the repo entirely.** The Zig project's code of conduct now prohibits AI-generated content in pull requests, issues, and comments — a structural response to both the noise and the risk AI introduces to the open-source contribution pipeline.
