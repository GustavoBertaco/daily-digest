## Netflix Tech Blog

**[Trading a Cloud Identity for Your Own: Workload Attestation on Managed Compute](https://netflixtechblog.com/trading-a-cloud-identity-for-your-own-workload-attestation-on-managed-compute-516d5a29b252?source=rss----2615bd06b42e---4)**
Most organizations run two identity systems simultaneously: one from the cloud provider (IAM roles, instance profiles, execution roles) and their own internal identity that services actually check for access decisions. On self-managed infrastructure you can bootstrap your own identity freely, but on managed compute the provider controls what credential a process receives. This Netflix Engineering post by Dhruv Pratap covers the mechanism for exchanging that cloud-provider credential for an internal workload identity via attestation.

## AWS What's New

**[Amazon Transcribe adds customer-managed KMS keys for custom resources](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-transcribe/)**
Amazon Transcribe now supports encrypting custom vocabularies, custom vocabulary filters, and custom language models at rest using a customer-managed symmetric AWS KMS key. Previously these custom resources were always encrypted with an AWS-owned key; if no key is provided the default behavior is unchanged.

**[Amazon EC2 M8i and M8i-flex instances are now available in additional regions](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ec2-m8i-m8i-flex-thf/)**
M8i and M8i-flex instances are now available in the AWS European Sovereign Cloud (Germany) region. Powered by custom Intel Xeon 6 processors available only on AWS, they offer up to 15% better price-performance and 2.5x more memory bandwidth compared to previous-generation Intel-based instances.

**[Amazon EC2 R8i and R8i-flex instances are now available in additional regions](https://aws.amazon.com/about-aws/whats-new/2026/09/ec2-r8i-r8i-flex-thf/)**
R8i and R8i-flex instances are now available in the AWS European Sovereign Cloud (Germany) region. Powered by custom Intel Xeon 6 processors available only on AWS, they deliver up to 15% better price-performance and 2.5x more memory bandwidth compared to previous-generation Intel-based instances.

**[Amazon EC2 C8i and C8i-flex instances are now available in additional regions](https://aws.amazon.com/about-aws/whats-new/2026/09/c8i-c8i-flex-thf-september-2026/)**
C8i and C8i-flex compute-optimized instances are now available in the AWS European Sovereign Cloud (Germany) region. Powered by custom Intel Xeon 6 processors available only on AWS, they deliver up to 15% better price-performance and 2.5x more memory bandwidth compared to previous-generation Intel-based instances.

**[AWS IAM outbound identity federation now supports interface VPC endpoints for OIDC discovery](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-sts-vpc-oidc/)**
IAM outbound identity federation's OIDC discovery metadata and JWKS verification key endpoints are now reachable from within a VPC via AWS PrivateLink, removing the requirement for traffic to traverse the public internet. This extends the federation model that lets AWS workloads access external resources without long-lived credentials.

**[AWS DataSync launches a monitoring dashboard for tracking task executions across your account](https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard)**
DataSync now provides an account-level monitoring dashboard in the console showing status, transfer rates, duration, and totals for each task execution. Executions can be filtered by status, task, mode, execution ID, or start time, with aggregate counts of successful and failed runs across the filtered set.
