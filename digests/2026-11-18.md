## AWS What's New

**[AWS Security Hub extends unified security management to Google Cloud Platform](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-gcp/)**
AWS Security Hub now monitors GCP resources alongside AWS, providing a single unified experience for risk analytics, cloud security posture management, vulnerability management, and security response across both clouds. Customers previously had to operate separate security tools per environment, making holistic risk prioritization difficult.

**[AWS IAM announces Access Troubleshooter to debug access denied errors](https://aws.amazon.com/about-aws/whats-new/2026/11/iam-access-troubleshooter/)**
IAM's new Access Troubleshooter surfaces the full authorization context behind an access denied error — including other policies evaluated during the request — rather than just the ARN of the denying policy. This replaces trial-and-error debugging with direct visibility into why a specific request was denied.

**[Amazon ECR now replicates image deletions across regions and accounts](https://aws.amazon.com/about-aws/whats-new/2026/11/replication-deletes-amazon-ecr)**
Amazon ECR now replicates image deletions and tag removals to configured destination regions and accounts, keeping destination repositories automatically consistent with the source. Teams running multi-region or multi-account architectures no longer need to script or manually manage deletions in each location.

**[Amazon EBS now supports associating additional KMS keys with snapshots](https://aws.amazon.com/about-aws/whats-new/2026/11/ebs-snapshots-associate-kms-keys/)**
EBS snapshots can now have additional KMS keys associated with them, allowing encrypted snapshots to be shared and copied across accounts without first re-encrypting them. The capability simplifies disaster recovery and backup workflows that move encrypted volumes between accounts with different key ownership.

**[Amazon S3 Vectors now supports hybrid search combining vector and full text for more relevant search results](https://aws.amazon.com/about-aws/whats-new/2026/11/s3-vectors-hybrid-search/)**
Amazon S3 Vectors now supports hybrid search, combining vector similarity search with full-text search in a single query and returning one unified ranked result list. The approach targets RAG, agent memory, and search applications, delivering subsecond response times through the existing S3 Vectors API.

**[Amazon Redshift now supports multi-statement transactions, conflict resolution, and time travel for Apache Iceberg](https://aws.amazon.com/about-aws/whats-new/2026/11/redshift-time-travel-multi-statement)**
Redshift adds multi-statement transactions, automatic write-conflict resolution, and time travel for Apache Iceberg tables, bringing warehouse-grade transaction semantics to Iceberg workloads. Batch jobs get all-or-nothing commits across multiple steps; concurrent streaming and scheduled jobs can write to the same tables simultaneously.

**[AWS DevOps Agent is now available in AWS GovCloud (US-West)](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-devops-agent-govcloud-west/)**
AWS DevOps Agent — which resolves and proactively prevents incidents across AWS, multicloud, and on-premises environments — is now available in AWS GovCloud (US-West). The agent learns application relationships, works with observability tools and runbooks, and handles on-demand SRE tasks.

**[Amazon Connect Health medical coding is now available in public preview](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-connect-health-medical-coding/)**
Amazon Connect Health adds a public preview of AI-assisted medical coding that uses existing clinical documentation to suggest ICD-10-CM and CPT codes, including E&M levels and modifiers, for provider or coder review before submission. The HIPAA-eligible capability integrates into EHR or billing applications through the Amazon Connect Health SDK.

**[Amazon Connect Customer agent assist now supports interactive responses](https://aws.amazon.com/about-aws/whats-new/2026/11/Connect-Custom-agent-interactive-responses)**
Amazon Connect's agent assist now supports interactive UI components — cards, carousels, buttons, and input fields — letting contact center agents review information, select options, and confirm actions without typing separate follow-up requests. The AI agent analyzes conversation context in real time and can execute tasks using MCP tools in Connect Customer or third-party services.

**[AWS KMS now supports key sharing with AWS Resource Access Manager](https://aws.amazon.com/about-aws/whats-new/2026/11/kms-key-sharing-resource-access-manager/)**
AWS KMS now integrates with AWS Resource Access Manager, providing a consistent mechanism to share KMS keys across accounts, within AWS Organizations, and with specific IAM roles and users. Trusted parties define access through reusable managed permissions in RAM while the key owner retains full control of key policies.
