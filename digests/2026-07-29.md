## The Data Engineering Show

**[AI Learns Through Continuous Data Conversations](https://www.youtube.com/watch?v=Tlw1ogzFGZ8)**
Chris Merrick argues that effective AI for data analytics is not a one-time implementation but a continuous process — the system's value grows through an ongoing feedback loop between the AI and its users.

- **Deployment is the starting point, not the goal.** The system improves through sustained interaction rather than reaching a fixed endpoint; treating launch as "done" forecloses its potential.
- **Going Deeper: handle increasingly complex problems.** The first scaling axis is continuously upgrading the AI to manage more complex data models and multi-step follow-up analysis questions as user demands grow.
- **Going Broader: extend into adjacent workflows.** The second axis is expanding the AI beyond core analytics into surrounding engineering and business workflows, giving it broader organizational context.
- **The feedback loop is the architecture.** Continuous conversation between system and user drives both axes — making that loop a first-class design concern rather than a post-launch afterthought.

## AWS What's New

**[Amazon Neptune now supports tag-based access control for IAM](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-neptune-tbac/)**
Neptune now supports tag-based access control (TBAC) for IAM, letting customers use AWS resource tags and IAM principal tags as conditions in IAM policies and Service Control Policies to govern Neptune data-plane operations. This provides the dynamic, attribute-based enforcement mechanism that organizations managing multiple clusters at scale needed beyond Neptune's existing VPC, TLS, and IAM authentication controls.

**[AWS Glue Data Quality now supports anomaly detection and writing results to the AWS Glue Data Catalog](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-glue-data-quality-catalog-anomaly-detection-write-results)**
Glue Data Quality adds anomaly detection for Catalog-based evaluations and the ability to write evaluation results directly to AWS Glue Data Catalog tables. Both capabilities work across ETL jobs and Catalog evaluations, enabling detection of unexpected shifts such as sudden drops in distinct values or row count spikes in GDC tables.

**[AWS Glue Data Quality now supports distribution statistics for data profiling](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-glue-data-quality-distribution-profiling)**
A new Distribution Analyzer in Glue Data Quality generates frequency distribution profiles — histograms for numeric columns and value distributions for categorical, date, and boolean columns. Custom bin counts are supported, with access via the Data Quality Definition Language (DQDL).

**[Amazon GameLift Streams now supports Custom Aspect Ratio and Dynamic Resolution](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-gamelift-streams/)**
GameLift Streams now lets you configure a specific resolution per stream session — portrait, landscape, ultra-wide, and square aspect ratios — eliminating letterboxing and pillarboxing across mobile phones, tablets, and non-standard displays. Dynamic Resolution adds further control over streaming quality under varying network conditions.

**[AWS Security Hub MCP App brings exposure findings into your AI-assisted workflow (Preview)](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-security-hub-mcp-app/)**
A new preview MCP server connects Security Hub exposure findings directly to Claude Desktop, enabling natural-language investigation of your security posture and reducing context switching and manual triage. The app lets you view top exposures and act on findings without leaving an AI-assisted workflow.

**[AWS Elemental MediaTailor adds configurable ad timeout and concurrency controls for improved ad fill and faster startup](https://aws.amazon.com/about-aws/whats-new/2026/07/mediatail-configurable-ad-timeout-and-concurrency)**

## AI Engineer

**[AI Agents for Performance: Ship Faster, Pay Less — Rajat Shah, Netflix](https://www.youtube.com/watch?v=CgsWxRUY5Eo)**
Rajat Shah from Netflix presents the case for deploying AI agents to surface and fix performance regressions that standard code review misses — compressing a slow, manual detection-to-fix cycle that leaves inefficiencies in production for months.

- **Code review doesn't catch algorithmic regressions.** A quadratic-time pattern in a tensor merge method was silently consuming CPU on every request at a live Netflix service — invisible to reviewers, but visible in a call stack.
- **The bottleneck is cycle time, not expertise.** The full manual loop — profiling, reading a flamegraph, tracing through the codebase, writing a fix, validating it — takes long enough that performance issues sit unaddressed in production for months before anyone looks.
- **AI agents compress the detection-to-fix cycle.** The core proposition is that agents can automate the slow, repetitive steps of performance investigation, enabling faster shipping and lower infrastructure cost.
