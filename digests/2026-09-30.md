## AWS What's New

**[AWS Systems Manager now supports sharing documents through AWS Resource Access Manager](https://aws.amazon.com/about-aws/whats-new/2026/09/systems-manager-sharing-documents-ram/)**
SSM Documents can now be shared with an entire AWS organization or specific OUs via AWS RAM, replacing the prior limit of sharing only publicly or with a static list of individual account IDs. Membership changes in an org or OU are automatically reflected, eliminating manual share-list maintenance as accounts are added or removed.

**[Amazon EC2 Future-dated Capacity Reservations Now Supports Postponing Start Dates](https://aws.amazon.com/about-aws/whats-new/2026/09/ec2-fcr-postpone-start-date/)**
EC2 Future-dated Capacity Reservations — which let customers lock in capacity up to 120 days ahead — now allow postponing the start date if plans change before delivery. A revised quote is presented with the new start date and updated commitment duration, which may increase depending on how late the postponement occurs.

**[Amazon Rekognition Face Liveness now returns Feedback Codes](https://aws.amazon.com/about-aws/whats-new/2026/09/rekognition-liveness-feedback-codes/)**
The `GetFaceLivenessSessionResults` API now returns Feedback Codes that identify specific conditions behind a low liveness score — poor lighting, face obstruction, closed eyes, or low video quality. Customers can surface these codes to end users so they can make targeted corrections and retry successfully, rather than facing a generic failure.

**[Grok 4.7 is now available on Amazon Bedrock](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-grok-4-7/)**
Amazon Bedrock now supports SpaceXAI's Grok 4.7 with US Geo and Global cross-Region inference. Grok 4.7 builds on Grok 4.6 with improved mixed-document handling, more dependable repo-scale coding with planning and error recovery, and enhanced browser-use agents for form fills and portal navigation.

**[Claude Sonnet 5.5 now available on AWS](https://aws.amazon.com/about-aws/whats-new/2026/09/claude-sonnet-5-5-aws/)**
AWS now offers Claude Sonnet 5.5, a step up from Sonnet 5 with stronger coding performance and lower cost per task at faster speed. It targets well-scoped tasks within larger coding workflows — such as building and fixing features end-to-end within a single session.

**[Claude Sonnet 5.5 now available on AWS GovCloud (US)](https://aws.amazon.com/about-aws/whats-new/2026/09/claude-sonnet-5-5-aws-govcloud-us/)**
Claude Sonnet 5.5 is now available in AWS GovCloud (US) regions, bringing the same coding and knowledge work improvements to government-regulated workloads that the commercial release delivers.
