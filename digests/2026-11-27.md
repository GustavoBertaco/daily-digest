# 🤖 AI & Machine Learning

## AI Engineer

**[Stop Building Software Factories — Justin McCarthy, Diffusion](https://www.youtube.com/watch?v=1S4hx3wgvBE)**
Justin McCarthy, CEO of Diffusion, argues that the dominant model for AI software development — routing every new idea through a rigid production pipeline — is the wrong abstraction for most work, and that the real engineering leverage lies in brownfield factories: continuous loops that protect and improve software customers already pay for.

- **New ideas don't belong in a factory.** When you don't yet know what you want, forcing nascent work through a production pipeline wastes time and tokens before the idea is validated.
- **Brownfield factories are the real target.** McCarthy's model centers on continuous loops that keep existing customer promises — getting faster, cheaper, and safer with each iteration rather than chasing net-new feature delivery.
- **Setup time is low and falling.** A brownfield factory takes about a week to stand up, and the architecture simplifies with each new model release.
- **Code abundance shifts the scarce resource.** With code increasingly cheap to generate, the constrained input becomes engineering judgment — knowing which promises to keep and which new ideas are actually worth building.

**[1,000 Claude Agents Formalized Fermat's Last Theorem — Lance Martin, Anthropic](https://www.youtube.com/watch?v=wrfbI5eyLAI)**
Lance Martin describes how a fleet of 1,000 Claude agents completed the Lean formalization of Fermat's Last Theorem in roughly 30 hours, using only Git and a database — with no domain-specific harness, no human steering on the solution path, and the coordination structure emerging from the agents themselves.

- **No bespoke harness, no human navigation.** The system ran on commodity primitives; the lead agent bootstrapped its own coordination tables rather than operating inside a purpose-built orchestration framework.
- **Dynamic self-reassignment at scale.** As work progressed, the agent team redistributed effort based on what remained — not a static assignment determined upfront.
- **Stronger models know what to write down.** Memory quality correlates with model capability; the progression from Sonnet 3.7 to Fable 5 produced measurably tighter memory management, illustrated through a Pokémon memory benchmark.
- **"Dreaming" as a consolidation strategy.** The snippet references a technique of processing transcripts to consolidate agent memory — an emergent pattern for managing long-horizon tasks without human checkpointing.
