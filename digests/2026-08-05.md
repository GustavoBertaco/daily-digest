## AWS What's New

**[AWS Transform continuous modernization is now generally available](https://aws.amazon.com/about-aws/whats-new/2026/7/aws-transform-continuous-general-available)**
AWS Transform continuous modernization — which helps engineering teams analyze and remediate technical debt across source code repositories — is now generally available in all supported AWS Regions. Teams can connect GitHub organizations, GitLab groups, and Bitbucket workspaces, run analyses on demand or on a recurring schedule, and prioritize findings across technical debt, security, agentic readiness, modernization readiness, and custom categories.

**[OpenAI GPT-5.6 Sol, Terra, and Luna now support 1 million token context windows on Amazon Bedrock](https://aws.amazon.com/about-aws/whats-new/2026/08/gpt-sol-terra-luna-long-context-bedrock)**
GPT-5.6 Sol, Terra, and Luna now support 1 million token context windows on Amazon Bedrock, enabling full codebases, lengthy documents, and multi-turn agent histories to be processed in a single request without chunking or information loss. Stated use cases include entire-repository code review and migration, and long-form legal or regulatory document processing.

**[Amazon GameLift Streams now supports sharing streams with stream URLs](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-gamelift-streams/)**
Amazon GameLift Streams now supports stream URLs that give end users temporary, unauthenticated access to a playable stream session in a supported web browser — no AWS account, credentials, or software installation required. Publishers set the URL validity duration and a maximum session count; each recipient who opens the link starts an independent stream session.

**[AWS Resilience Hub now provides recommended resilience tests](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-resilience-hub/)**
AWS Resilience Hub now generates pre-configured resilience tests for platform engineering and SRE teams based on each service's architecture, configuration, and resilience policy. Tests use AWS Fault Injection Service (FIS) to inject controlled faults and evaluate whether the service recovers within defined recovery objectives.

**[AWS Organizations now provides maximum account quota visibility in Service Quotas](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-organizations/)**
AWS Organizations customers can now view their maximum account quota and current utilization directly in AWS Service Quotas, removing the need to contact AWS Support or account teams to determine current limits. This enables proactive account growth planning and quota increase requests before reaching the limit, accessible from the management account's Service Quotas console.

**[AWS Lambda Provisioned Mode for Amazon SQS event source mappings now supports up to 10,000 event pollers](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-Lambda-provisioned-sqs-esm-max-pollers/)**
AWS Lambda Provisioned Mode for SQS event source mappings now supports up to 10,000 event pollers — a 5× increase from the previous limit of 2,000 — enabling up to 100,000 concurrent invocations. The higher ceiling targets highly responsive event-driven applications such as real-time order processing and financial transaction systems.

**[Amazon EC2 I7i instances now available in Asia Pacific (Thailand) and Israel (Tel Aviv) Regions](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-i7i-instances-in-additional-regions/)**
Storage Optimized Amazon EC2 I7i instances — powered by 5th Gen Intel Xeon Processors at 3.2 GHz all-core turbo — are now available in Asia Pacific (Thailand) and Israel (Tel Aviv). They deliver up to 23% better compute performance and more than 10% better price performance over I4i instances, with up to 45 TB of NVMe storage via 3rd generation AWS Nitro SSDs.

**[Amazon SageMaker AI serverless model customization now supports full fine-tuning](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-sagemaker-fft)**
Amazon SageMaker AI serverless model customization now supports full fine-tuning for over 25 open-source models, including families from gpt-oss, Gemma, Llama, Nemotron, and Qwen. In addition to parameter-efficient methods like LoRA, teams can now update all model parameters for deeper domain adaptation when use cases require it.

**[AWS Transform for full-stack Windows modernization now supports offline schema transformation to Aurora PostgreSQL](https://aws.amazon.com/about-aws/whats-new/2026/7/aws-transform-windows-sql-schema-aurora)**
AWS Transform for full-stack Windows modernization now supports offline source transformation, enabling customers to convert Microsoft SQL Server databases to Amazon Aurora PostgreSQL without a live database connection. The capability covers SQL Server storage objects via AWS DMS and code objects such as stored procedures, using an agentic, interactive experience.

**[AWS WAF now supports Miggo Security managed rule groups for emerging threats and AI/ML application protection](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-waf-miggo-managed-rule-groups)**
AWS WAF now supports two managed rule groups from Miggo Security via AWS Marketplace: one targeting high emerging application threats and one focused on AI/ML application protection. Both provide continuously updated protection against actively exploited vulnerabilities, those with public proof-of-concept code, or entries in the CISA Known Exploited Vulnerabilities (KEV) catalog — without requiring custom rule authoring.
