## AWS What's New

**[AWS Transfer Family now supports source IP preservation for SFTP servers behind a Network Load Balancer (NLB)](https://aws.amazon.com/about-aws/whats-new/2026/09/transfer-family-sftp-source-ip-nlb/)**
AWS Transfer Family now preserves the client's original source IP address when an NLB sits in front of an SFTP server using a VPC-hosted endpoint, via Proxy Protocol v2. Previously the NLB replaced the client IP with its own private address, making IP-based auditing, access controls, and compliance logging unreliable when using a customer-managed NLB.

**[AWS HealthOmics now supports IAM session policies](https://aws.amazon.com/about-aws/whats-new/2026/09/omics-iam-session-policy/)**
AWS HealthOmics now supports IAM session policies, enabling dynamic per-run permission scoping without creating a separate IAM role for each tenant or run. The capability reduces IAM role sprawl in multi-tenant bioinformatics workflows on a HIPAA-eligible service.

**[AWS Batch now supports bulk job cancellation and termination](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-batch-bulk-cancellation/)**
New CancelJobs, TerminateJobs, and TerminateServiceJobs APIs let operators cancel or terminate up to 50 jobs in a single call and receive per-job results in a single response. ListJobs now returns isCancelled and isTerminated fields, and ListServiceJobs returns isTerminated, simplifying status tracking for large-scale batch workloads.

**[Introducing Amazon EC2 T8i instances](https://aws.amazon.com/about-aws/whats-new/2026/09/ec2-t8i-instances-ga/)**
EC2 T8i instances are now generally available in nano, micro, small, and medium sizes, powered by custom sixth-generation Intel Xeon 6 processors built on sixth-generation Nitro cards — available exclusively on AWS. They deliver up to 30% better price-performance compared to T3 and target low-to-moderate CPU utilization workloads.
