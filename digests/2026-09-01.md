## AWS What's New

**[Amazon OpenSearch Service adds new Cluster Insights for faster diagnosis of cluster status](https://aws.amazon.com/about-aws/whats-new/2026/08/opensearch-cluster-status-insight/)**
Amazon OpenSearch Service has expanded Cluster Insights with 17 new insights targeting Red and Yellow cluster status, providing root-cause identification and actionable recommendations to resolve them. Coverage includes resource exhaustion scenarios — JVM out-of-memory and sustained CPU saturation — alongside configuration issues such as zone imbalance and misconfigured replica counts. The update directly addresses the previous gap in unassigned-shard root-cause diagnosis.

## AWS Blog

**[AWS Weekly Roundup: Welcome DuckLabs to the team, Agentic Resource Discovery (ARD), and more (August 31, 2026)](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-welcome-ducklabs-to-the-team-agentic-resource-discovery-ard-and-more-august-31-2026/)**
AWS has signed a definitive agreement to acquire DuckLabs, the Amsterdam-based company behind DuckDB — the open-source in-process analytical database that executes SQL directly against Parquet, CSV, and JSON files. DuckDB will remain open source under its independent foundation and MIT license. AWS plans to combine DuckDB's query speed with the enterprise scale of its own services over time.

## Databricks Blog

**[Autoscaling Lakebase Postgres](https://www.databricks.com/blog/autoscaling-lakebase-postgres)**
Databricks introduces autoscaling for Lakebase Postgres, addressing the challenge of committing to a database instance size before a workload's demands are understood. The post frames upfront instance sizing as an outdated provisioning pattern.
